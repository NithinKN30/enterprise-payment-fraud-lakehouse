# Enterprise Payment Fraud Detection Lakehouse

## Overview

An end-to-end Azure Data Engineering project for building a scalable
payment fraud detection lakehouse.

## Business Objective

The platform ingests payment transactions from multiple sources,
processes batch and streaming data, applies data quality and fraud
detection rules, and provides curated datasets for analytics.
